# Alexandar Ivanov - portfolio site (zanderproduction.nl)

Plain static site hosted on GitHub Pages. No build step.

- `index.html` - all the text on the site
- `style.css` - the design
- `script.js` - lists for the sliders (vlogs, sets, remixes, posters), showreel and reels
- `cv.pdf` - CV
- `images/` - posters, logos, icons
- `CNAME` - tells GitHub Pages to use zanderproduction.nl
- `preview-blue/` - test version with the dark blue colours (not linked from the site)

Every change pushed to the main branch goes live within a minute or two.

## Editing pages
All pages are generated by `tools/build.py` (home, work/*, dj/). Edit the text there and run `python3 tools/build.py`, then commit.
The old one-page version is kept on the branch `archive-onepager-2026-11-10`.
